    - Remove lines: 3, 23 and edit line 24

## Start the Base64Decoder
1. Place `base64_decoder.py` in a local folder, such as your [Python virtual environment](https://github.com/vand3rlinden/Python?tab=readme-ov-file#installation-of-python): `~/py_envs/scripts`
2. Enable your virtual Python environment: `source ~/py_envs/bin/activate`
3. Browse to the path: `cd py_envs/scripts`
4. Start **Start the Base64Decoder**: `python3 base64_decoder.py`
